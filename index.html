Legal & Privacidad

Documentación oficial de PichonBot — el bot de la comunidad de Pichon_8.

Última actualización: Marzo 2026

01

Aceptación de los Términos

Al interactuar con PichonBot en cualquier servidor de Discord, aceptas estos términos de uso. Si no estás de acuerdo, te pedimos que no uses el bot.

02

Descripción del Servicio

PichonBot es un bot privado de Discord diseñado exclusivamente para la comunidad de Pichon_8. Sus funciones incluyen:

  • Anuncios automáticos de streams en vivo en Twitch, YouTube, TikTok, Kick e Instagram.
  • Notificaciones de nuevos vídeos publicados.
  • Gestión de mensajes en canales de Discord.
  • Asistente de IA con Gemini para responder preguntas de la comunidad.
  • Comandos de administración para los moderadores del servidor.
03

Uso Permitido

El uso de PichonBot está restringido a los servidores de Discord autorizados por el propietario. Queda estrictamente prohibido:

  • Intentar explotar, hackear o modificar el bot sin autorización.
  • Usar el bot para enviar spam, contenido ofensivo o ilegal.
  • Intentar acceder a datos de otros usuarios a través del bot.
  • Redistribuir o copiar el código del bot sin permiso explícito.
04

Comandos de Administración

Los comandos /live, /liveall, /next, /video, /message-* y /logs están reservados exclusivamente para usuarios con permisos de Administrador en el servidor. El abuso de estos comandos puede resultar en la revocación del acceso.

05

Disponibilidad del Servicio

PichonBot se proporciona "tal cual" sin garantía de disponibilidad continua. El propietario se reserva el derecho de modificar, pausar o discontinuar el servicio en cualquier momento sin previo aviso.

06

Modificaciones

Estos términos pueden actualizarse en cualquier momento. El uso continuado del bot tras una actualización implica la aceptación de los nuevos términos.

01

Datos que Recopilamos

PichonBot recopila únicamente los datos mínimos necesarios para su funcionamiento:

  • Nombre de usuario de Discord — para registrar quién ejecutó un comando de anuncio.
  • IDs de canales — para enviar notificaciones al canal correcto.
  • Contenido de mensajes mencionando al bot — exclusivamente para procesar respuestas de IA en el canal designado.
  • Datos de streams y vídeos — título, enlace y plataforma, almacenados en base de datos para evitar notificaciones duplicadas.
02

Datos que NO Recopilamos

  • Contraseñas, tokens ni credenciales de ningún tipo.
  • Mensajes privados (DMs) de usuarios.
  • Información personal como email, dirección o datos de pago.
  • Historial de conversaciones con la IA — cada mensaje es independiente.
  • Datos de usuarios menores de edad de forma intencionada.
03

Uso de los Datos

Los datos recopilados se usan exclusivamente para:

  • Enviar notificaciones de streams y vídeos correctamente.
  • Evitar anuncios duplicados mediante registros en base de datos.
  • Generar logs de actividad para diagnóstico técnico.
  • Procesar preguntas enviadas a la IA integrada.
04

Almacenamiento y Retención

Los datos se almacenan en una base de datos privada MySQL alojada en servidores seguros. Los registros de notificaciones se limpian automáticamente de forma periódica para mantener la base de datos ligera. Los logs del bot se almacenan solo en memoria y se borran al reiniciar el servidor.

05

Servicios de Terceros

PichonBot se integra con los siguientes servicios externos, sujetos a sus propias políticas de privacidad:

  • Discord API — para el funcionamiento del bot.
  • Google Gemini API — para las respuestas de IA.
  • Twitch API — para detección de streams en vivo.
  • YouTube Data API — para detección de nuevos vídeos.
  • TikTok Live Connector — para detección de lives en TikTok.
06

Tus Derechos

Puedes solicitar en cualquier momento la eliminación de tus datos almacenados contactando con el equipo de soporte en nuestro servidor de Discord. Atenderemos tu solicitud en un plazo razonable.

01

Medidas de Seguridad

PichonBot implementa las siguientes medidas para proteger el servicio y sus usuarios:

  • Las credenciales (tokens, API keys) se almacenan en variables de entorno .env nunca expuestas públicamente.
  • El bot opera solo en servidores autorizados mediante Guild ID fijo.
  • Los comandos sensibles requieren permisos de Administrador en Discord.
  • El bot solo puede editar o eliminar sus propios mensajes, nunca los de otros usuarios.
02

Control de Acceso

El sistema de permisos funciona de la siguiente manera:

  • Usuarios regulares — solo pueden usar /help y mencionar al bot en el canal de IA.
  • Administradores — acceso completo a todos los comandos del bot.
  • Bot owner — control total sobre la configuración y despliegue del bot.
03

Protección contra Abusos

  • La IA integrada solo responde en el canal designado, evitando spam en otros canales.
  • Los servicios automáticos incluyen manejo de errores para evitar bucles de notificaciones.
  • El sistema detecta si un stream ya fue anunciado antes de enviar una nueva notificación.
  • Los errores de APIs externas se registran en logs sin interrumpir el funcionamiento general.
04

Vulnerabilidades Conocidas

Si descubres una vulnerabilidad de seguridad en PichonBot, te pedimos que no la hagas pública y la reportes de forma responsable a través de nuestro servidor de soporte en Discord. Agradecemos la colaboración responsable de la comunidad.

05

Actualizaciones de Seguridad

El bot se mantiene actualizado con las últimas versiones de sus dependencias. Las actualizaciones críticas de seguridad se aplican con la mayor rapidez posible. Se recomienda a los administradores del servidor estar atentos a los anuncios del canal oficial.
